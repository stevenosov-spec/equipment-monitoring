# Equipment Monitoring System

Прототип десктопного приложения для **непрерывного мониторинга технологического оборудования**, разработанный в рамках лабораторных работ по дисциплине «Программная инженерия».

Приложение имитирует поступление данных с промышленных датчиков, отображает состояние оборудования в реальном времени, регистрирует отказы, рассчитывает общую эффективность оборудования (OEE) и формирует отчётность в формате Excel.

---

## 🔧 Основные возможности

- **Симуляция технологических параметров**  
  Плавное изменение значений (температура, давление, вибрация, расход) с возвратом к среднему — имитирует реальный технологический процесс.

- **Цветовая индикация состояния**  
  Каждая единица оборудования отображается в виде плитки с цветом: зелёный — норма, жёлтый — предупреждение, красный — авария, серый — нет данных.

- **Регистрация и обработка отказов**  
  Автоматическое выявление выхода параметров за допустимые границы, расчёт приоритета отказа, подтверждение оператором с автоматическим удалением из списка через 3 секунды и переводом оборудования в нормальное состояние.

- **Таблица параметров в реальном времени**  
  Для выбранного оборудования отображаются текущие значения всех параметров, единицы измерения и время последнего обновления (обновляется каждую секунду).

- **Тренды изменения параметров**  
  Отображение графика изменения выбранного параметра за любой период с настраиваемым масштабом (последний час, сутки, неделя, месяц, произвольный). На график наносятся верхняя и нижняя границы допуска (красные пунктирные линии).

- **Расчёт OEE**  
  Для выбранного оборудования в реальном времени рассчитываются и отображаются показатели: доступность, производительность, качество, общий OEE.

- **Сводный отчёт по OEE**  
  Генерация Excel-файла с расчётом OEE для всех единиц оборудования за произвольный интервал времени (от 1 секунды до нескольких лет). Перед формированием отчёта запрашивается период через удобное диалоговое окно.

- **Excel-отчёт по отказам**  
  Выгрузка списка всех отказов за последнюю неделю в формате Microsoft Excel.

- **Мультиязычность (заглушка)**  
  Базовая поддержка переключения русского/английского интерфейса (переменная `_currentLanguage`).

- **Удобный интерфейс**  
  Главное окно разделено на три зоны: левая панель управления со списком установок и кнопками, центральная область с индикаторами, OEE и таблицей параметров, правая панель со списком активных отказов.

## 🧱 Архитектура и технологии

Приложение построено в соответствии с трёхслойной архитектурой:

| Слой | Проект | Назначение |
|------|--------|-----------|
| **Уровень представления** | `EquipmentMonitoring.App` | WPF-интерфейс (MVVM) |
| **Бизнес-логика** | `EquipmentMonitoring.Core` | Сервисы мониторинга, отказов, отчётов, OEE, моделей |
| **Интеграция** | `EquipmentMonitoring.Integration` | Симулятор датчиков (может быть заменён на реальные OPC UA/Modbus) |

**Стек технологий:**

- **.NET 8 (Windows)** — целевая платформа
- **WPF + MVVM CommunityToolkit** — пользовательский интерфейс
- **Entity Framework Core 8 + MySQL** — ORM и база данных
- **OxyPlot** — визуализация графиков (тренды)
- **ClosedXML** — генерация Excel-файлов
- **Microsoft.Extensions.DependencyInjection** — внедрение зависимостей
- **Git** — система контроля версий

## 🚀 Запуск проекта

### Требования к окружению

- **Windows 10/11**
- **.NET 8 SDK** (установите с https://dotnet.microsoft.com/)
- **MySQL Server 8.0** (локально или удалённо)
- **MySQL Workbench** (опционально, для работы с БД)
- **Visual Studio 2022** (Community Edition) или **Visual Studio Code** с Extensions
