# Документация системы мониторинга оборудования

Добро пожаловать в документацию проекта **Equipment Monitoring System** – прототипа десктопного приложения для непрерывного мониторинга технологического оборудования.

## Быстрый старт

- [Функциональная документация](docs/functions.md) – описание модулей и сервисов.
- [API‑документация](api/) – сгенерированное описание классов и методов.
- [README](README.html) – общая информация о проекте.

## О проекте

Разработано в рамках лабораторных работ по дисциплине «Программная инженерия».  

Приложение имитирует поступление данных с датчиков, отображает состояние оборудования, регистрирует отказы, рассчитывает ОЕЕ и формирует отчёты Excel.
